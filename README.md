# JalDrishti - Assam flood watch (research demonstration)

**Live map:** https://jay123anta.github.io/jal-drishti/

An experimental flood-watch map for Assam. It gathers free public rain,
river, satellite and official-alert data every 3 hours and uses one
small statistical model per river basin to colour 105 villages
green / yellow / red for the day ahead. Official government alerts are
shown above everything else.

> **⚠ This is a research demonstration, NOT a flood warning system.**
> The colours are estimates and can be wrong. Real flood warnings come
> from **ASDMA, CWC and your District Administration** - always follow
> them, not this map.
